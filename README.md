# Time and Limit Landing Page

## Overview
This is the official landing page for the Time and Limit browser extension. The page is designed to introduce the extension's capabilities, highlight its core features, and provide users with a clean, engaging interface to install the extension.

## Technologies Used
The landing page is built using standard web technologies without the need for heavy frameworks:
- HTML5: For semantic structure and layout of the index and privacy pages.
- CSS3: For styling, responsive design, animations, dark mode variables, and the neo-brutalist aesthetic.
- JavaScript: For handling interactivity, such as the dark mode toggle and the FAQ accordion behavior.

## Project Structure
- index.html: The main landing page.
- privacy.html: The privacy policy document.
- style.css: The main stylesheet containing all design tokens and responsive rules.
- script.js: Client-side logic for the user interface.
- logo.svg: The application logo.

## How to Run
Since this is a static website, you can view it by simply opening the index.html file in any modern web browser. For a better development experience, you can serve the directory using any local web server.
